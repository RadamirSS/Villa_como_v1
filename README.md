# Villa Como — интерактивная демонстрация умного дома

🔗 **Работающая демонстрация:** https://villa-como-showroom-radamirs-projects-fe4c51cc.vercel.app/

Клиентский демонстрационный интерфейс с 3D-моделью виллы, этажами, сценариями освещения и управлением группами.

## Запуск

```bash
npm install
npm run dev
```

Проверки: `npm test`. Сборка: `npm run build` (включает тесты). Приложение работает локально и не требует сервера умного дома.

## Возможности

- Законченная архитектурная 3D-сцена с фасадом, кровлей, меблированной террасой, отдельным гаражом и ландшафтом.
- Поворот, масштаб, отдельный просмотр 1–3 этажей и гаража, кликабельные группы света.
- Семь световых сценариев и независимые регуляторы групп, ночной/дневной свет, автотур и экспорт PNG.
- Интерфейс, адаптированный для телефона и планшета.

Техническая интерпретация, соответствие исходным листам и обязательные оговорки: [docs/DESIGN_BASIS.md](docs/DESIGN_BASIS.md).

## Источники

Основано на дизайн-проекте MÈTRE «Вилла на озере Комо»: A-18–A-21 (мебельные планы), A-34–A-37 (освещение), A-03–A-06 (обмеры), A-10–A-13 (монтаж). Геометрия фасада, кровля, озеленение и положения части световых маркеров — художественная 3D-интерпретация. Это не BIM и не исполнительная схема электрики.

Сценарии в демо меняют визуальное состояние, но не управляют реальным оборудованием. Проходные/перекрёстные выключатели и физическая автономность управления от Wi-Fi должны проверяться отдельно в электротехническом проекте.

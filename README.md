# Villa Como — интерактивная демонстрация умного дома

Клиентский демонстрационный интерфейс с 3D-моделью виллы, этажами, сценариями освещения и управлением группами.

## Запуск

```bash
pnpm install
pnpm run dev
```

Проверка геометрии: `pnpm run check:geometry`. Сборка: `pnpm run build`. Приложение работает локально и не требует сервера умного дома.

## Источники

Основано на предоставленном 94-страничном дизайн-проекте MÈTRE «Вилла на озере Комо»: A-18–A-21 (мебельные планы), A-34–A-37 (освещение), A-03–A-06 (обмеры). Контуры и комнаты оцифрованы в метрах; гараж справа под 90° и выход террасы во двор внесены по уточнению владельца. Наружные фасады, кровля и участок интерпретированы: соответствующих фасадов и генплана в комплекте нет.

Подробное сравнение предыдущей модели с проектом, измеримые расхождения и оставшиеся допущения: [MODEL_AUDIT.md](docs/MODEL_AUDIT.md). Геометрия: `src/data/architecture.js`.

Сценарии в демо меняют визуальное состояние, но не управляют реальным оборудованием. Проходные/перекрёстные выключатели и физическая автономность управления от Wi-Fi должны проверяться отдельно в электротехническом проекте.

В интерфейсе у каждой группы показан уровень достоверности: **по рабочему листу**, **по плану · ориентир** или **демо-группа**. Кнопка «Паспорт модели» раскрывает границу между документированными данными и художественной 3D-интерпретацией.

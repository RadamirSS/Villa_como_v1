# Villa Como — интерактивная демонстрация умного дома

Клиентский демонстрационный интерфейс с 3D-моделью виллы, этажами, сценариями освещения и управлением группами.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Приложение работает локально и не требует сервера умного дома.

## Источники

Основано на дизайн-проекте MÈTRE «Вилла на озере Комо»: A-18–A-21 (мебельные планы), A-34–A-37 (освещение), A-03–A-06 (обмеры), A-10–A-13 (монтаж). Геометрия фасада, кровля, озеленение и положения части световых маркеров — художественная 3D-интерпретация. Это не BIM и не исполнительная схема электрики.

Сценарии в демо меняют визуальное состояние, но не управляют реальным оборудованием. Проходные/перекрёстные выключатели и физическая автономность управления от Wi-Fi должны проверяться отдельно в электротехническом проекте.

В интерфейсе у каждой группы показан уровень достоверности: **по рабочему листу**, **по плану · ориентир** или **демо-группа**. Кнопка «Паспорт модели» раскрывает границу между документированными данными и художественной 3D-интерпретацией.
